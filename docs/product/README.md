# Product Docs

Product contract files live here. Prefer small domain-named docs over one
monolithic SPEC. Create files when a story needs them — empty structure is
healthier than fake product truth.

- [Image stores](images.md) describes signed public and private image URLs,
  WebP compression, and the Node.js, Rust, and Go clients.
- [Knotree Registry integration for App services](knotree-registry-integration.md)
  records the proposed pull credential, signed webhook, and digest deployment
  contract before implementation.
