Knotree API is deployed as {{ include "knotree-api.fullname" . }}.

The API reads DATABASE_URL from the existing Kubernetes Secret {{ .Values.secrets.existingSecret }}.
Create it before installing:

  kubectl create secret generic {{ .Values.secrets.existingSecret }} \
    --from-literal={{ .Values.secrets.databaseUrlKey }}='postgres://user:password@postgres.example/knotree_cloud' \
    --namespace {{ .Release.Namespace }}

The migration hook runs before install and upgrade. The Traefik route is:
  https://{{ .Values.ingress.host }}
{{- if .Values.env.appServicePublicDomain }}

Public App service domains use:
  https://<random-subdomain>.{{ .Values.env.appServicePublicDomain }}
Point the wildcard DNS record *.{{ .Values.env.appServicePublicDomain }} to this ingress
and ensure the TLS issuer can issue a wildcard certificate.
Image URLs are served from:
  https://img.{{ .Values.env.appServicePublicDomain }}
The Cloudflare cache Worker must stay deployed so public image URLs cache for one year.
{{- end }}
